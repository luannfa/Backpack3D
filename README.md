# BackPack3D CRUD

Este projeto oferece uma aplicação simples em Flask para cadastro de modelos 3D.

## Requisitos
- Python 3
- Dependências listadas em `requirements.txt`

## Como executar
```bash
pip install -r requirements.txt
python app.py
```
A aplicação ficará disponível em `http://localhost:5000`.

É possível cadastrar itens informando nome, descrição, disciplina, imagem e arquivo STL. A listagem permite filtrar por disciplina ou pesquisar pelo nome. Os arquivos cadastrados podem ser baixados.
